## 2. Step-by-Step Player & Villager Workflow

```
[ Female Villager Mother ]            [ Male Villager Father ]
      (Gene: G_mother)                      (Male Genome)
              \                                  /
               +---------------+----------------+
                               |
                               v
                       [ Breeding Event ]
                               |
                               v
                     Is Offspring Female?
                       /              \
                    (No)              (Yes)
                     /                  \
           [ Flat Male Profile ]         v
                                 [ Mutation Step ]
                                 delta = (rand - 0.5) * 0.15
                                 G_daughter = clamp(G_mother + delta, 0.0, 1.0)
                                         |
                                         v
                                  [ Baby Phase ]
                                  Visible: FLAT
                                         |
                                         v (Reaches Adulthood)
                                  [ Adult Female ]
                                  Render: 0.7f + (G_daughter * 0.5f)
```

1. **Courtship & Child Creation**: When two villagers produce a child, MCA's breeding system triggers chromosome genetic crossover.
2. **Maternal Allele Sampling**: The daughter's initial breast size gene is derived from the mother's expressed trait $G_{\text{mother}}$.
3. **Mutation Application**: A randomized mutation variance $\Delta_{\text{mutation}}$ is calculated and added to the maternal value.
4. **Range Clamping**: The resulting daughter gene $G_{\text{daughter}}$ is strictly clamped between $0.0$ and $1.0$.
5. **Childhood Suppression**: While the offspring is a baby or child (`visuals.baby() == true`), the breast render layer suppresses mesh generation.
6. **Adult Phenotypic Expression**: Upon reaching adulthood, the 3D model box renders with scale $S_{\text{scale}} = 0.7 + (G_{\text{daughter}} \times 0.5)$.

## 3. Mathematical Genetics & Scaling Formulas

### Maternal Inheritance with Mutation
The genetic calculation is executed within `GeneticsBridge.calculateInheritedBreastGene(float motherGene)`:
$$\Delta_{\text{mutation}} = (R - 0.5) \times 0.15, \quad R \sim \text{Uniform}(0, 1)$$
$$G_{\text{daughter}} = \max\left(0.0, \min\left(1.0, G_{\text{mother}} + \Delta_{\text{mutation}}\right)\right)$$

Where:
- $R$ is a pseudo-random floating-point value generated by Minecraft's `RandomSource`.
- $\Delta_{\text{mutation}}$ has a maximum range of $[-0.075, +0.075]$.
- $G_{\text{daughter}}$ is guaranteed to lie within $[0.0, 1.0]$.

### Model Scale Translation Formula
When passing the trait into Mojang's `PoseStack` inside `McaBreastRenderLayer`:
$$S_{\text{scale}} = 0.70 + 0.50 \times G_{\text{expressed}}$$

- Minimum Scale ($G = 0.00$): $0.70\times$ baseline.
- Median Scale ($G = 0.50$): $0.95\times$ baseline.
- Maximum Scale ($G = 1.00$): $1.20\times$ baseline.

## 5. SNBT & Visuals Component Schema

MCA villagers store genetic and visual snapshots in their internal NBT/Data components. The bridge reads these fields through MCA's client snapshot record `VillagerVisuals`:

```json
{
  "VillagerVisuals": {
    "female": true,
    "baby": false,
    "breastSize": 0.654,
    "skin": "mca:textures/skins/skin/female/2.png",
    "skinGene": 0.42,
    "genderDataName": "female"
  }
}
```

## 7. Developer & Addon Extension Hooks

Developers creating MCA addons or custom village mechanics can invoke the genetics bridge directly:

```java
package com.dasik.mcagenderbridge.genetics;

// Direct Java API call
float motherGene = 0.55f;
float daughterGene = GeneticsBridge.calculateInheritedBreastGene(motherGene);
```
