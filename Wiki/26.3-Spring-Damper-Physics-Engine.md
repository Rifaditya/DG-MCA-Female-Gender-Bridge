## 2. Step-by-Step Physics Update Workflow

```
[ Client Entity Tick / Render Frame ]
                 |
                 v
   [ Query McaBreastPhysicsEngine ]
   getPhysicsState(entity, targetBreastSize)
                 |
                 v
      Is Entity or Target <= 0.02f?
         /               \
      (Yes)              (No)
       /                   \
[ Reset State to 0 ]        v
                    [ Motion Delta Calculation ]
                    motion = currentPos - lastPos
                    speed = |motion|
                    vertVel = motion.y
                           |
                           v
                    [ Spring-Damper Numerical Integration ]
                    forceY = -vertVel * 2.0 - (posY * springK)
                    velocityY = (velocityY + forceY) * damping
                    posY = clamp(posY + velocityY, -0.4, 1.2)
                           |
                           v
                    [ Lateral & Rotational Coupling ]
                    forceX = -motion.x * 1.5 - (posX * springK)
                    velocityX = (velocityX + forceX) * damping
                    posX = clamp(posX + velocityX, -0.3, 0.3)
                    rot = clamp(velocityY * 15.0 + speed * 10.0, -20.0, 20.0)
                           |
                           v
                    [ Apply to PoseStack Matrix ]
```

## 3. Mathematical Physics & Harmonic Oscillator Equations

The physics engine models breast movement as a **damped harmonic oscillator** subjected to external entity inertial forces:

$$m \ddot{x} + c \dot{x} + k x = F_{\text{inertial}}$$

Where:
- $m = 1.0$ is the normalized unit mass.
- $k = 0.25$ is the spring stiffness coefficient.
- $c = 0.75$ is the fluid damping factor.

### Vertical Axis ($Y$) Integration
$$\begin{aligned}
F_Y &= -2.0 \cdot v_{\text{vertical}} - (k \cdot y_t) \\
v_{Y, t+1} &= \left(v_{Y, t} + F_Y\right) \cdot c \\
y_{t+1} &= \text{clamp}\left(y_t + v_{Y, t+1}, -0.4, 1.2\right)
\end{aligned}$$

### Horizontal Lateral Axis ($X$) Integration
$$\begin{aligned}
F_X &= -1.5 \cdot v_X - (k \cdot x_t) \\
v_{X, t+1} &= \left(v_{X, t} + F_X\right) \cdot c \\
x_{t+1} &= \text{clamp}\left(x_t + v_{X, t+1}, -0.3, 0.3\right)
\end{aligned}$$

### Rotational Pitch Tilt ($\theta$) Coupling
$$\theta_{t+1} = \text{clamp}\left(15.0 \cdot v_{Y, t+1} + 10.0 \cdot \|\vec{v}\|, -20^\circ, +20^\circ\right)$$

### Smooth Phenotypic Transition (Lerp)
When a villager's size changes (e.g., during editor modifications), size interpolates smoothly:
$$S_{t+1} = \text{lerp}\left(0.1, S_t, S_{\text{target}}\right) = S_t + 0.1 \cdot (S_{\text{target}} - S_t)$$

## 5. EntityPhysicsState In-Memory Data Structure

```java
public static class EntityPhysicsState {
    public float positionY;          // Current vertical displacement
    public float positionX;          // Current lateral displacement
    public float bounceRotation;      // Pitch tilt in degrees
    public float currentBreastSize;  // Smoothed active size scale

    private float velocityY;         // Vertical velocity accumulator
    private float velocityX;         // Horizontal velocity accumulator
    private float velocityRot;       // Angular velocity accumulator
    private Vec3 lastPos;            // Previous tick position vector
}
```

## 6. Exhaustive Physics Parameter Matrix

| Parameter | Code Variable | Numerical Value | Physical Unit | Gameplay Effect |
| :--- | :--- | :--- | :--- | :--- |
| **Spring Stiffness** | `springK` | `0.25f` | $N/m$ | Determines speed of return to rest position |
| **Damping Factor** | `damping` | `0.75f` | Dimensionless | Suppresses unnatural rubbery oscillation |
| **Vertical Boost** | `forceY` multiplier | `2.0f` | Dimensionless | Translates jump / fall velocity into bounce |
| **Lateral Boost** | `forceX` multiplier | `1.5f` | Dimensionless | Translates strafing into side sway |
| **Max Upward Travel** | `positionY` upper | `+1.2f` | Blocks / Units | Prevents mesh clipping into head / neck |
| **Max Downward Travel**| `positionY` lower | `-0.4f` | Blocks / Units | Prevents mesh dropping into legs |
| **Max Pitch Angle** | `bounceRotation` | `\pm 20.0f` | Degrees | Natural rotational tilt when running/falling |

## 7. Developer & Addon Extension Hooks

The physics engine is designed with **zero per-tick allocations** (`ConcurrentHashMap` lookup + primitive field updates). Addon developers can inspect or hook into entity physics states:

```java
import com.dasik.mcagenderbridge.physics.McaBreastPhysicsEngine;
import com.dasik.mcagenderbridge.physics.McaBreastPhysicsEngine.EntityPhysicsState;
import net.minecraft.world.entity.LivingEntity;

LivingEntity villager = ...;
EntityPhysicsState state = McaBreastPhysicsEngine.getPhysicsState(villager, 0.8f);

float currentYOffset = state.positionY;
float pitchTilt = state.bounceRotation;
```
