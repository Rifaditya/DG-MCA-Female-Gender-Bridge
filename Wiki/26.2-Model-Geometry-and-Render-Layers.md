```

          Pass Render Pre-Conditions?

                     |

       )
```

## 3. Mathematical Geometry & UV Coordinate Specifications

### 1. Cuboid Geometry Definition
The breast model is defined using Minecraft's `CubeListBuilder` in `McaBreastModelBox.createLayerDefinition()`:
- **Origin**: $X_0 = -4.0\text{F}, Y_0 = 0.0\text{F}, Z_0 = -2.0\text{F}$
- **Extents**: $\Delta X = 8.0\text{F}, \Delta Y = 4.0\text{F}, \Delta Z = 3.0\text{F}$
- **Deformation**: `CubeDeformation(0.0F)`

### 2. Texture UV Projection
The model utilizes UV offset `(18, 20)` on a standard $64 \times 64$ skin texture map:
- **Front Face**: Maps from $(18 + \Delta Z, 20 + \Delta Z) = (21, 23)$ with dimensions $8 \times 4$.
- **Top / Bottom Faces**: Map horizontally across width $8$ and depth $3$.
- **Side Faces**: Left and right faces occupy $3 \times 4$ pixels.

### 3. Transformation Matrix Translation
$$\mathbf{T}_{\text{chest}} = \begin{bmatrix}
1 & 0 & 0 & 0.00 \\
0 & 1 & 0 & +0.12 \\
0 & 0 & 1 & -0.10 \\
0 & 0 & 0 & 1
\end{bmatrix}$$

Following translation, uniform scaling is applied based on genetic trait expression:
$$\mathbf{S}_{\text{genetic}} = \text{diag}(S, S, S, 1), \quad S = 0.70 + 0.50 \times G_{\text{breast}}$$

## 5. LayerDefinition Codec & Construction Schema

```java
public static LayerDefinition createLayerDefinition() {
    MeshDefinition mesh = new MeshDefinition();
    PartDefinition root = mesh.getRoot();

    root.addOrReplaceChild("breasts", CubeListBuilder.create()
            .texOffs(18, 20)
            .addBox(-4.0F, 0.0F, -2.0F, 8, 4, 3, new CubeDeformation(0.0F)), PartPose.ZERO);

    return LayerDefinition.create(mesh, 64, 64);
}
```

## 6. Exhaustive Render Property Reference Table

| Property | Value | Rationale |
| :--- | :--- | :--- |
| **Submit Order** | `1` | Renders immediately after base body mesh to prevent depth buffer clipping |
| **Cutout Type** | `RenderTypes.entityCutout` | Alpha cutout handling allowing transparent clothing overlays |
| **Cull State** | `false` | Disables face culling so chest underside is visible from low camera angles |
| **Overlay Texture** | `OverlayTexture.NO_OVERLAY` | Clears damage flash buffers unless entity is actively hurt |
| **Light Mapping** | `packedLight` | Receives exact dynamic block/sky light of the parent villager |
| **Outline Color** | `renderState.outlineColor` | Respects glowing effects and spectral arrow outlines |

## 7. Developer & Addon Extension Hooks

```java
// Attaching custom render layers in EntityRenderer Mixins
@Inject(method = "<init>", at = @At("RETURN"))
private void attachCustomLayer(EntityRendererProvider.Context ctx, VillagerEntityModelMCA model, CallbackInfo ci) {
    this.addLayer(new McaBreastRenderLayer(this));
}
```
