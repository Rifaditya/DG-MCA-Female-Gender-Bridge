## 2. Step-by-Step Compilation Workflow

### Step 1: Environment Check
Verify your installed Java level is 25:
```bash
java -version
```

### Step 2: Configure Workspace
Ensure `gradle.properties` references JDK 25:
```properties
minecraft_version=26.2
loader_version=0.16.10
fabric_version=0.152.1+26.2
mod_version=1.3.1+26.2
maven_group=com.dasik.mcagenderbridge
archives_base_name=mca-female-gender-bridge
org.gradle.java.home=E:/JDK25
fabric.loom.suppressJavaCompatibilityChecks=true
loom.suppressJavaCompatibilityChecks=true
```

### Step 3: Run Build Command
Build the release JAR without daemon caching:
```bash
./gradlew build --no-daemon
```
